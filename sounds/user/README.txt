User custom sounds

Put your own .ogg, .mp3 or .wav files in this folder, then fully restart WoW (a /reload does not pick up new files).
Add them from the Sounds page with Add Custom Sound, using just the file name, then pick them on any event.

BLU Classic updates replace this whole addon folder, this folder included. Keep a copy of your sounds, or put them in
Interface\AddOns\BLU_Sounds\ instead (a folder next to BLU Classic that updates never touch). BLU Classic looks in both.
